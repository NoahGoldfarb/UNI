(2.6) Lemma: Für eine Abb. $\alpha: A \to B$ gelten:
(a) $\alpha$ Injektiv gdw. $\exists B_0 \subset B \exists \beta \in \operatorname{Abb}(B_0, A): \alpha \beta = \mathrm{id}_{A} $ 
(b) $\alpha$ surjektiv (auf B) gdw. $\exists \gamma \in \operatorname{Abb}(B, A): \gamma \alpha = \mathrm{id}_{B} $
Bem: ist $A \neq \emptyset $, so bleibt (a) richtig wenn wir starr $B_0 = B$ setzen. Dann ist $\beta = \alpha ^{-1}$ wie im beweis unten nicht immer ausreichen. ...

Bew: (a) Ist $\alpha$  Injektiv, So haben wir $B_0 = \operatorname{Bild}(\alpha) und \beta = \alpha ^{-1}$
Seien nun $B_0 \subset B \text{  und } \beta : B_0 \to A \text{ mit } \alpha \beta = \mathrm{id}_{A} $ gegeben. 
Z.z. $\alpha$ injektiv. Seien $a, \tilde{a} \in A $mit $a \alpha = \tilde{a} \alpha $. Dann folgt tatsächlich $$a = a. \mathrm{id}_{A} = a. \alpha \beta = (a \alpha) \beta = ()\tilde{a} \alpha )\beta , \alpha \beta = \tilde{a}. \mathrm{id}_{A} = \tilde{a} $$
(b) Sei zunächst $\alpha$ surjektiv auf B. injeden b $\in B$ finden wir ein $a_b \in A$ mit $a_B \alpha = b$ wir definieren $\gamma B \to A$ mittels $b \gamma = a_b$ für bel $b \in B$ gilt dann $b (\gamma  \alpha ) = (b \gamma ) \alpha  = a_b \alpha  = b$, also ist $\gamma \alpha  = \mathrm{id}_{B} $ Sei nun umgekehrt $\gamma : B \to  A$ mit $\gamma \alpha  = \mathrm{id}_{B} $ gegeben. Z.z. $\alpha$ ist surj. auf B Sei $b \in B$ gegeben, und setzte $a = b \gamma \in A$. Dann gilt tatsächlich $$b = b \mathrm{id}_{B} = b (\gamma \alpha ) = (b \gamma ) \alpha = a \alpha \in  \operatorname{Bild}(\alpha ) $$

Hierfür wird für (*) das Auswahlaxiom verwendet.

2.7 Hilfssatz  Eine Abb. $\alpha: A \to B$ ist eine bijektion von A auf B gdw. $\beta , \gamma : B \to A \text{   ex. mit }\alpha \beta = \mathrm{id}_{A} \text{ und }  \gamma \alpha  = \mathrm{id}_{B}  $ in disessm Fall gilt bereits B = Bild( $\alpha$) und $\beta$= $\gamma$ = $\alpha ^{-1}$
Bew: Sei $\alpha: A \to B$ bijektiv Insb. bildet $\alpha$ surjektiv auf B ab. und somit liefert das lema 2.6 Die Abbildung $\beta = \alpha ^{-1}$  und $\gamma$ mit $\alpha \beta  = \mathrm{id}_{A}, \gamma \alpha = \mathrm{id}_{B}  $
Sind umgekehrt $\beta$ und $\gamma$: $B \to A$ gegeben mit $\alpha \beta  = \mathrm{id}_{A} $, $\gamma \alpha  = \mathrm{id}_{B} $ so liefert (2.6) direkt $\alpha$ ist injektiv und surjektiv auf B 
Den zusatz begründen wir so: Wegen $\gamma \alpha = \mathrm{id}_{B} $ $\operatorname{Bild}(\alpha ) = B$. Weiter ist $\beta = \mathrm{id}_{B} \beta  = (\gamma \alpha ) \beta  = \gamma (\alpha \beta ) = \gamma \mathrm{id}_{A} \gamma  $ Die Bedingungen  $\alpha \beta = \mathrm{id}_{A} \text{ und }  \beta  \alpha  = \mathrm{id}_{B} $ liefern dann $\gamma = \beta = \alpha ^{-1}$
