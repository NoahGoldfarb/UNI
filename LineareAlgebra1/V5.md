# 3 Abzahlen und mächtigkeit von Mengen

(3.1) (a) Zwei Mengen A, B heißen Gleichmächtig (auch: von gleicher Mächtigkeit / Kardinalität), falls es eine Bijektion $f: A \to B$ gibt. Wir schreiben dann $A \approx B$
Merke: Offenbar gelten dann für Mengen A, B, C: (i)$ A \approx A;$
(ii) $A \approx B \iff B \approx A$; (iii)aus A $\approx$ B und B $\approx$ C folgt A $\approx$ C

(b) Eine Menge A heißt endlich, falls A $\approx \{1, 2, 3, 4, ..., n\}$ für geeignetes n in $\mathbb{N}_0$ ist in diesem Fall $f: \{1, 2, 3, ..., n\} \to A$ eine Bijektion so gilt offenbar $A = \{a_1, a_2, ..., a_n\}$ wobei diel elemente $a_i = f(i)$, $1 \leq i \leq n$ paarweise verschieden sind. ist A nicht endlich so heißt A undendlich. z.b. ist $\mathbb{N}$ undendlich. Für $m, n \in \mathbb{N}_0 gilt: \{1,2 , 3, ..., m\} \approx \{1,2 , 3.., n\}$ gdw: $n = m$ 

Dem entsprechen def. wir die Mächtigkeit einer Menge A als  $$A = |A| = \begin{cases}n falls A \approx \{1, 2, 3, ..., n\} für ein n \in \mathbb{N} \\
  \inf andernfalls\end{cases}$$
