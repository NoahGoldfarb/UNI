# 2 Prädikatenlogik (Frege 1879)
ein Prädikat ist eine Aussage, die vom wert einer Variable abhängt., d.h. die einen platzhalter hat.

bsp: A(x): $x>2$ 
Def: $\forall$ : A(x) für alle x gilt die aussage A(x) (Allquantor) 
bsp: $\forall x: (x \in R \land x > 1)\implies x^2 >1$.
Def: $\exists x : A(x)$ heißt: Es gibt ein x, es existiert ein x für das A(x) gilt.
bps: $\exists x : (x \in R \land x^2 = 2)$

$\neg \exists x : A(x)$ ist äquivalent zu $\forall x: \neg A(x)$
$\neg (\forall x:A(x))$ ist äquivalent zu: $\exists x: \neg A(x)$ es stimmt nicht, dass für alle x A(x) wahr ist. ist äquivalent zu es existiert ein x für das A(x) falsch ist. 
Beispiel: $\neg \exists x \in Q \land x^2 = 2$ ist äquivalent zu $\forall x: \neg x\in Q \land x^2 = 2$ bzw. zu $\forall X: x \notin \lor x^2 \neq 2$ Hier wure $\neg (A \land B) = \neg A \lor \neg B$ verwendet. 

Bem: die math. Konstruktion einer logik ist komplizierter. z.b. muss man den zusammenhang zwischen der Konstruierten (innere Logik) und der Logik, die für die Argumente verwendet wird (Äußere Logik) genauer berücksichtien.
