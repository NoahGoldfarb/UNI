# 1. Reele und Komplexe Zahlen
## 1.1 Mengen und Abbildungen
Die Konstruktion von der Mengenlehre wird in dieser Vorlesung nicht durchgeführt, sondern die Mengenlehre wird nur beschrieben. Für präzise Details wie im Vorkurs siehe Literatur auf Vorkurs-website. 
Naive Definition der Mengenlehre 1.1: (Cantor 1874):
Eine Menge ist eine Zusammenfassung bestimmter wohlunterschiedener objekte unserer Anschauung oder unseres Denkens – welche die elemente der Menge genannt – werden zu einem Ganzen. 
Bsp, 1.2: $$M = \{2, 4, \pi, e\}$$, $$\mathbb{N} = \{0, 1, 2, 3, 4, ...\}$$ ist die Menge der natürlichen Zahlen, $$\mathbb{Z} = \{...,-3, -2, -1, 0, 1, 2, 3, ...\}$$ ist die Menge der ganzen Zahlen $$
\mathbb{Q} = \{1, -1, \frac{1}{2}, \frac{-1}{2}, \frac{1}{3}, \frac{2}{3}, \frac{4}{3}\}
$$ist die Menge der rationalen zahlen
Die Konstruktion dieser Mengen und der Rechenoperationen ($+, \times , -, :$) wird in dieser Vorlesung ohne beweis vvorausgesetzt, aber im 4. Sem. nachgeholt. obige naive Definition ist sehr schwammig, Viel schlimmer: Sie wiederspricht sich selbst: Nach def. 1.1 wird eine Menge eind. durch die elemente charakterisiert, die sie enthält, Z,B. wir die Menge M = $\{5, 7, 11\}$ eindeutig bestimmt, dass 5, 7 und 11 elemente der Menge sind ($5 \in M, 7\in M, 11 \in M$ und für alle anderen Objekte x gilt, dass $x \notin M$). 
Def. 1.3: Die Leere Menge $\emptyset $ sei diejenige Menge,die kein Element enthält, bei der für alle objekte x gilt: $x \notin \emptyset$ Eine Menge N heißt teilmenge einer Menge M, geschrieben $N \subseteq M$, falls jedes Element von N auch Element von M ist. 
Beispiel: $\{2, 4, 6\} \subseteq \{1, 2, 3, 4, 5, 6, 7\}$ Insbes. ist $\emptyset \subseteq M$ für jede Menge M.  Die Notation für Teilmengen, die durch eine Bedingung beschrieben werden ist analog zu: $$
\{0, 1, 2,3\} = \{n \in \mathbb{N}_0 | n \leq 3\}
$$ wobei | wie "mit" oder " für die gilt" gelesen wird. Z.b. $$
\{4, 5, 6, 7\} = \{n \in \mathbb{N}_0 | n > 3\text{ und } n \leq 7\}
$$
